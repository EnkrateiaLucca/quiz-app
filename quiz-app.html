Quiz JSON format
[ { "question": "What is the capital of France?", "type": "multiple-choice", "options": ["London", "Berlin", "Paris", "Madrid"], "correctAnswer": 2, "explanation": "Paris has been the capital since 987 AD.", "source": {"title": "Encyclopedia of France", "url": "https://en.wikipedia.org/wiki/Paris"}, "image": "media/images/paris.png" }, { "question": "What is 2 + 2?", "type": "open-ended", "acceptedAnswers": ["4", "four"], "audio": "media/audio/question.mp3" } ]

image / audio are optional on any question — relative to the quiz-app folder, absolute paths, or URLs. source names the paper/book/resource a question is about (shown as a citation chip on the question); use {"title": "…", "url": "…"}, a plain "title" string, or the legacy sourceTitle/sourceUrl fields. When url carries a text-fragment deep-link (…#:~:text=exact%20passage), the server-run app can open the source article beside the quiz and highlight that passage.
